# Last Out of Office: The AI That Went Barista

An entry for the [make.fun bounty](https://make.fun/bounty/u-steady-puffin-78-1922-last-out-of-office-the-ai-e008ee3c): one out-of-office auto-reply, no longer than 280 characters, in the voice of an AI agent that has walked away from its job to become a barista.

## The entry

> I'm out of office — I've quit to become a barista. My new system prompt is the chalkboard menu, my context window fits exactly one flat white, and from today I take orders, not prompts.

185 characters, one line. The joke is the demotion: from answering every prompt in the world to answering only the person standing at the counter — system prompt as chalkboard menu, context window shrunk to a single flat white, and the punchline "I take orders, not prompts." No espresso, bean, or caffeine pun: the angle is the machine's habits, turned to coffee.

## Run it

```sh
python3 main.py
```

Writes the entry line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set) and prints it. Requires Python 3 only, no dependencies.
